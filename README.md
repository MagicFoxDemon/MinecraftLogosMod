# Logos（逻各斯）
> **在这里，魔法不是现成的技能，而是一门有类型、事件驱动、靠魔力计量的语言。**
Logos 中没有「火球术」或「连锁闪电」这样写死的法术按钮。所谓「火球术」，不过是**「塑成魔弹 → 命中时造成火焰伤害 → 消散时灼烧周遭敌人」**；所谓「连锁闪电」，则是**「射线命中目标后 → 自目标处再折射向下一名敌人」**。只要掌握了符文语法，**你能写下什么，就能施展什么**。

## ✨ 模组亮点速览
- **可视化术式编纂（术式工坊）**：在羊皮纸节点画布上连线构筑法术，支持百余个正交符文节点、实时语法与类型检查、单次施放魔力估算、意图推断，以及 40+ 篇内置示例术式模板。
- **三原质七大符文家族**：涵盖启式、形体、运动、指向、变化、律式与数量运算；支持主动蓄力、被动触发（受伤/攻击/击杀时）以及自动化法阵发射。
- **🗣 言出法随（离线语音施法）**：内置纯本地语音声纹比对引擎，不依赖联网、不限语言与方言——录三遍自己的声音，挂上**言灵坠**，按住右键喊出咒语名即可当场施法。
- **☉ 书灵（可选 AI 术式助手）**：在工坊中用自然语言描述你想要的法术（例如*「向前方发射一枚追踪最近敌人的火球」*），书灵会自动查阅你已领悟的符文与示例、编写并通过编译器校验，一键预览到画布。
- **⚗ 伟大功业（炼金产线与魔力工业）**：工艺卡连线式**炼金术桌**（发酵、溶解、蒸馏、沉淀、煅烧、净化、升华七大工艺）、13 种魔法植物罐栽培养、区块级**魔力场**扩散与阻隔，以及红石/定时驱动的**术式发射器**。
- **✦ 鲜活的造物与伙伴**：可定制心核术式的**魔力生命体**、能乘肩同行或亲自驾驶发射掌心炮的**炼金术巨像**、生物使魔与末影龙驾驭，以及**车万女仆「施法」模式**深度联动。

## 🚀 三步快速上手
初次进入世界时，系统会自动赠送一本 **《逻各斯手记》** 放在你的快捷栏最后一格（若不慎遗失，可用 `书 + 青金石` 重新合成）。手记中包含图文引导、配方查询以及随游戏进度动态解锁的「符文图鉴」。
### 第一步：备齐基础器物
1. **木法杖**：使用任意 7 种原版木材合成对应木法杖（或进一步合成**木长杖**），每根可挂载 3 张载页。
2. **基础术式载页**：由 `纸 + 金粒` 合成空白载页。
3. **术式编纂台**：由 `基础术式载页 + 书与笔 + 讲台` 合成。
### 第二步：铭刻第一道术式
1. 手持空白载页**右键**点击术式编纂台，将载页铺在台面上。
2. 再次**右键**打开 **术式工坊**（或潜行右键直接取回载页）。
3. 在画布上将节点连接为 `术式 → 魔弹 →（命中时）→ 伤害`，也可以直接在右侧「模板」列表选择 **「启蒙魔弹」** 并点击「载入模板」。
4. 确认右侧总览显示 `✓ 成立` 后，点击下方带蜡封的 **「写入术式载页」**。
### 第三步：挂载与施放
1. **潜行右键**术式编纂台取回写好的载页。
2. 手持法杖**潜行右键**打开法杖槽位，把载页放进去。
3. 按 **R** 键（可在按键设置中更改）打开**术式轮盘**选中术式，**按住右键蓄力，蓄满松开**即可施放！
> 💡 **想在创造模式先体验全套内容？**  
> 输入命令 `/logos kit`，即可直接获赠装满官方示例术式的高阶法杖与**法式典籍**、全套编纂/拓印/炼金台、空白载页与锚钉。

## 🔯 符文体系：三原质与七大家族
Logos 借鉴炼金术「三原质」思想，将百余个符文划分为七个清晰的语法家族：
| 家族 | 图标 | 核心职责 | 代表符文与用法举例 |
| --- | --- | --- | --- |
| **启式** | `☉` | 定义术式名称、注入魔力上限、触发时机与 AI 意图 | `☉ 主动施放`、`☽ 受伤时`、`♂ 攻击时`、`♇ 击杀时`（后三者为被动术式，持杖即可自动生效） |
| **盐·形** | `🜔` | 构筑魔力在世界中的几何形态与存续载体 | **魔弹**、**射线**、**光柱**、**领域**、**游脉**（贴地爬行或攀爬墙面/天花板）、**炼成体**（方块/墙/平台/圆盾/穹顶，可阻挡或允许穿行并触发踏上事件）、**扇形分裂** |
| **汞·流** | `☿` | 决定魔弹与游脉的行进轨迹 | `→ 直行`、`⌒ 抛物`、`⌖ 追踪`、`⟳ 环绕`（护身环绕）、`∿ 游走`、`↺ 折返`、`〰 蛇行`、`◌ 环扩`、`◜ 弧扫` |
| **汞·指向** | `☌` | 搜寻实体/方块、类型筛选、坐标计算与锚点定位 | `最近之敌`、`周遭诸敌/玩家/掉落物/方块`、`种类筛选`、`视线落点`、`偏移`、`异界对应点`、命名**锚点（`^名字`）** |
| **硫·变** | `🜍` | 对实体、自身与天地施加真实效果 | 伤害/群伤、治疗/渡魔/护盾、控制/推拉/缴械/授装、药水、**魔力缠绕**、**处决**、**闪现**、**附身**、**化身**、**召唤使魔**、**无形之手**、**时间加速**、**天气/落雷**、**生长/衰退**等 |
| **律式** | `♄` | 控制术式的分支、循环、延迟与递归流向 | `若则`、`逐个实体`、`逐个方块`、`重复`、`延迟`、`择路`、`衔尾递归`、`熄灭` |
| **数·量** | `⚖` | 提供数值计算、状态读取与逻辑判断 | 四则运算、正弦/三角/锯齿/方波、随机数、调和、当前/已损生命、两点距离、剩余魔力、逻辑与或非、实体/方块匹配 |
### 七大元素属性特色
在 `伤害`、`群体伤害` 等效果中选择合适的元素，可以应对不同战况：
- `🜃 物理`：视作近战物理攻击，受护甲与保护附魔减伤影响。
- `🜂 火焰`：火焰伤害，**单点伤害魔力消耗全元素最低**；但天生免疫火焰的生物（如烈焰人、恶魂等）完全免疫。
- `🜄 寒霜`：穿透护甲的魔法伤害；**对天生免疫火焰的生物造成双倍伤害**，完美克制火免敌人。
- `🜁 雷霆`：穿透护甲的魔法伤害；**目标处于水中或正在淋雨时，伤害提高 50%**。
- `🜀 虚空`：**真实伤害**，无视护甲、保护附魔与抗性提升；相应地，单点伤害耗魔最高。
- `✶ 奥秘`：穿透护甲的稳定魔法伤害，对各类生物均无额外增减伤。
- `🜚 生命`：穿透护甲的魔法伤害（无法通过常规符文之书领悟，具有特殊获取途径）。

## 🪄 器物、载页与成长体系
### 1. 魔杖与长杖的差异化手感
- **魔杖（Wand）**：**按住右键**持续将体内魔力注入术式，蓄满后松手放出（蓄满前松手或切换物品会导致已注入魔力散逸为**游离魔力**）。
- **长杖（Staff）**：**平日按住左键**提前把魔力充入杖内储存，战斗时**轻点右键**即可消耗杖内储能**瞬发**术式，无需现场罚站蓄力。
### 2. 八档品级进阶与无损升级
法器从低到高共分八档：**木制（T1，7 种原版木材） → 紫晶（T2） → 回响（T3） → 炼金（T4） → 白垩（T5） → 天穹（T6） → 贤者（T7） → 至高（T8，创造专属）**。
