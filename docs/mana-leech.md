# 魔力水蛭

实体 ID：`logos:mana_leech`。初始生命值 20，搜索半径 24 格，二者可在 `logos-common.toml` 的 `manaLeech` 下调整。

自然生成使用主世界敌对生物的暗处 / 地面条件，单只生成，权重 5。只有自然生成（或世界生成）的原始水蛭有分裂资格；命令、刷怪笼、召唤生成的水蛭和分裂子代都没有该资格。

## 行为

在范围内选取当前魔力最多的玩家或玩家使魔，平分时选择更近的目标。忽略旁观、创造模式和死亡玩家。普通使魔以当前生命值表示魔力，魔力生命体与巨像使用它们已有的魔力池。每十 tick 重新择优，不以最大容量替代当前余额。

进入目标三格内且有视线后停止前进，蓄力三十 tick，伴随身体膨胀、核心亮起、粒子和音效。有效受击、目标远离三格或丢失目标会打断蓄力并重新判断。结束后实际扑向脸部，附着点随目标的头部朝向、俯仰和位置更新。

接触后吸附六十 tick，在第二十、四十、六十 tick 各吸取最多十魔力。实际吸取量不超过目标当前余额；对玩家还以其魔力上限截断余额。没有魔力可取时不会虚增水蛭的魔力或攻击力；已经开始的吸附仍保持三秒，目标死亡 / 消失则提早松开。

吸附期间，使用带原版击退（`minecraft:knockback`）附魔的剑有效近战命中，可以提前把水蛭从脸上击飞。命中后立即解除挂接，恢复碰撞与重力，向攻击者反方向上抛，再由原版击退力度继续推动；落地后重新寻找目标。普通剑、非剑武器、箭矢、法术及无敌 / 被取消的伤害不会触发这一脱附。剑同时带节肢杀手时仍正常遣散魔力。

攻击力从二开始，按实际累计吸取量增长：`2 + 累计吸取魔力 / 10 × 2`。同一秒先扣魔力、增长攻击力，再造成本次伤害。简单与普通难度使用一倍攻击力，困难一点五倍；使用不会再次进行原版难度缩放的魔法伤害类型。

普通使魔只承受吸取对应的生命伤害，不再叠加上述攻击伤害；仅把实际扣除的生命计入水蛭所得。魔力生命体和巨像扣其真实魔力，并承受法术攻击。三秒后掉落，落地后继续搜寻、靠近和蓄力。

## 分裂与掉落

只有有资格的原始水蛭当前储魔达到六十时才尝试分裂。十六格内活水蛭数量包含自身，少于五只才可开始；两秒 / 四十 tick 完成时再次检查，防止同时分裂超过该数量。受节肢杀手遣散后不足六十会停止分裂。无法分裂的水蛭仍可吸取魔力，不把魔力强行截为六十。

分裂把母体替换为两只子代，母体没有死亡掉落；子代出生魔力与累计吸取量为零，也没有再次分裂的资格。世代标记随存档保存。

- 原始水蛭死亡：储存魔力的百分之八十变成游离魔力，另掉一个 `logos:tainted_mana_shard`（被污染的魔力碎片）。
- 分裂子代死亡：不掉游离魔力，掉二至三个同种碎片；之后吸取过魔力也保持这个掉落规则。

## 节肢杀手

水蛭在原版 `minecraft:sensitive_to_bane_of_arthropods` 标签中，使用原版附魔伤害加成。额外的固定 `+n` 规则已取消。

带该附魔的真实近战武器有效命中后，一级遣散当前储魔百分之二十，二级百分之三十，之后每级加百分之十，最高全部遣散；遣散量在命中处生成游离魔力。累计吸取量和已增长的攻击力不回退。法术、箭矢不会继承攻击者当前主手剑上的附魔。

先执行遣散扣除，再计算致命击后剩余魔力的百分之八十，避免重复返还。子代仍受武器遣散规则影响，但死亡本身只掉碎片。

## 模型、动画与死亡特效

游戏资源保留第三版十段动画与第四版两段扑脸动画，另附与运行时三十 / 六十 / 四十 tick 对齐的动作。模型根骨的大幅视觉位移被运行时片段移除，实际扑击由实体移动负责。

死亡爆浆留给维护者制作。搜索 `TODO_MANA_LEECH_DEATH_BURST`，在 `ManaLeech.onDeathBurst` 添加效果；客户端死亡动画第十八 tick（0.9 秒）调用一次。当前空函数没有喷溅、爆浆几何或音效。
